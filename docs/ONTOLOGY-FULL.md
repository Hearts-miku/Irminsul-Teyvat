# 全库本体索引 v0.9.0

本版本将本体检索从水仙十字结社试点扩展到全部本地原文。这里的“全量”指现有语料的索引覆盖，不表示所有游戏内容已收齐，也不表示所有人物关系已人工确认。

## 使用

在剧情目录选择“实体与名词索引”，搜索人物、组织、地点、任务或世界观名词，按类型筛选。选中对象后点击“开放实体关联资料（含后续剧情）”会新建对话并保留原会话。主窗口和桌宠均支持直接提问、选择同名对象、切换实体专题、追问和查看出处。

普通章节中只使用当前剧情进度允许的证据；主线沿用累计开放所选章节及此前章节的规则。跨范围找到名词时只提供专题入口，不直接传出原文与关系。主动开放实体专题才会跨页面检索该对象的资料，可能包含后续剧情。

## 覆盖与质量

- 5,352 个来源页面，176,482 个原始解析片段；2,234 个转引副本不重复建索引。
- 22,600 个扫描名称均有处理决定：22,493 个纳入，107 个通用词或解析标记排除。
- 加上来源页面节点并拆分类型后，共 22,523 个实体／候选；22,430 个有正文证据，93 个仅有名称线索，不能开放空专题。
- 21,816 条显式字段关联：所属组织、国家、位置、任务地区、系列任务、出场人物。每条关联绑定来源修订、原始页哈希和片段哈希。
- 13 个跨类型同名名称拆分保存，148 个存在多对象映射的别名保留消歧；只使用已记录的重定向作为额外别名，不猜测秘密身份。
- 12,685 个名词仍待分类，2,511 个说话者仍待消歧。正文提及只作为检索入口，不冒充人物之间的事实关系；自动字段也明确标注尚未逐条人工核对。

水仙十字结社原有人工整理的四条关系仍可使用。全库自动索引不替代这类带有观点归属与反驳语境的人工整理。任意因果、阵营变化、时间顺序与同名异人均不能仅凭共现自动确认。

## 查询流程

问题 → 名称／别名定位 → 意图识别与同名消歧 → 当前剧情范围过滤 → 字段关系及正文提及召回 → 证据哈希校验 → 排序与同路径上下文 → 离线片段或在线模型讲解 → 引用回查。

证据保留原页面、字段／选项路径和说话人。来源变动的旧索引不能参与新回答。在线模型仅收到本轮通过范围校验的原文，不获得全库知识。此前摘要检索、未开放剧情限制和效果资料占位继续生效。

## 维护

运行 `npm run ontology:build` 重新扫描并构建。普通 `npm run build` 与打包会校验仓库自带索引的来源快照及全部原始片段哈希，无需采集缓存。显式重建 `npm run ontology:build` 需要本地已采集的源码缓存；它不会调用在线模型或产生模型费用。

- `data/ontology/index.json`：运行时节点、别名、证据和关联。
- `test-results/ontology-candidates.json`：原始候选与提取方式。
- `data/ontology/decisions.json`：每个名称的纳入、拆分或排除决定。
- `tests/ontology-full.test.mjs`：覆盖、全量哈希、范围隔离、同名消歧、追问、失效证据与 API 回归。
- `scripts/test-ontology-full-desktop.mjs`：实际打包程序主窗口与桌宠交互验证。

当前仍需人工工作的内容是语义整理与质量复核，而非这些名称的运行时接入：候选分类、同类型同名人物分离、额外可靠别名、动态关系与因果事实逐条核对。源站缺口另见 REVIEW-TASKS.md。
