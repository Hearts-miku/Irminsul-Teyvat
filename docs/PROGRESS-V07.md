# v0.7 内容与剧情进度

2026-10-01，在 v0.6 的 1,661 页基础上新增 400 页（200 页任务、200 页 NPC）。现有 2,061 页、105,031 个自动解析片段，其中 1,657 页包含对白标记。NPC 独立页面已取得 201 页；任务正文中另有大量 NPC 对话，不能和人物页数相加。

右侧「选择已入库主线」直接提供 51 个主线入口，按当前目录倒序列出，包含目录中最后的后续章节。这里的“最新”指已入库目录，不是对游戏官方实装版本的独立确认。来自更新专题的未核实章节仍在范围说明中标注。

「调整剧情进度」支持主线章节、精选摘要、原文任务与 NPC、提纲和全部范围筛选；可以按地区及名称查找，每页 20 项，不再默认只展示最初三段蒙德内容。窄屏通过顶部「剧情进度」进入同一窗口。选择后先展示范围，确认才切换；范围不变时不执行清空。

主线范围包含章节入口和原始资料“系列任务”字段明确关联的已入库子任务，例如「不动鸣神，恒常乐土」包含 8 个子任务。只按明确关系关联，不通过人物提及或标题近似扩展范围。来源仍指向各子任务自己的修订与正文；子任务数量不代表所有对白已核对。

章节范围使用新的独立 ID，v0.6 的单页会话范围保持不变。改变当前会话范围会清空当前对话，其他会话保留。已取得的原文和原来的 146 条精选资料分别统计，原文不自动变为已核对摘要。

本轮两次续传各获得 200 页，随后来源站返回 HTTP 567。第二次已将批次间隔降至至少 15 秒；失败后停止，保留缓存和 3,273 页缺口。未运行后台持续采集。详细分类见 [覆盖报告](CORPUS-COVERAGE.md)。
