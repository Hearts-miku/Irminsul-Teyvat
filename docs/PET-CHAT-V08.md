# v0.8 桌宠直接对话

原先桌宠只是主窗口的入口，没有输入框和回答区域。现在点击精灵会在桌宠窗口中展开小对话面板，无需唤起主窗口即可提问。

- 输入问题按 Enter 发送，Shift + Enter 换行；支持建议追问和出处展开。
- 共用主窗口当前会话、剧情范围和已保存的在线模型配置。设置仍在主窗口填写，桌宠不单独存储密钥。
- 回答完成后同步另一窗口；生成期间另一窗口禁止重复发送。停止按钮在发起讲解的窗口操作。
- 减号或 Esc 收起面板，草稿与会话保留；收起不会中止生成。出处展开时 Esc 先关闭出处。
- 拖动精灵移动窗口；展开时禁用鼠标穿透，窗口尺寸按显示器工作区限制。右上角箭头打开完整窗口。
- 历史会话保存在本地；未发送草稿仅在当前进程保留。

本轮不新增剧情资料，沿用 v0.7 的内容及缺口。测试使用独立数据目录和本机模拟模型，不使用真实密钥。
