## 出处与内容边界

数据位于 `data/liyue-story.json`，生成器与蒙德正文共用结构，保留稳定资料 ID、子任务名、来源定位、核对层次和取得的修订号。回答可展开具体子任务出处；全文页面读取失败时，明确降为检索摘录或任务索引。

- 第一幕总览来自 [浮世浮生千岩间](https://wiki.biligame.com/ys/浮世浮生千岩间) 的公开检索摘录。单独核对了 [请仙](https://wiki.biligame.com/ys/index.php?title=请仙&oldid=665440)、[惊变](https://wiki.biligame.com/ys/index.php?title=惊变&oldid=675171)、[望舒](https://wiki.biligame.com/ys/index.php?title=望舒&oldid=675201)、叠山、留云及返尘的相关片段。部分索引的前置条件与并行栏不一致，未将页面顺序当成唯一任务顺序。
- 第二幕流程依据 [辞行久远之躯](https://wiki.biligame.com/ys/index.php?title=辞行久远之躯&oldid=673276)，人物片段分别指向往生、指月、传香、壶天、市井、邀约等任务。椰奶误会使用 [归终（任务）](https://wiki.biligame.com/ys/index.php?title=归终（任务）&oldid=667059) 的可读检索片段，同名“归终”人物页面不作为该任务对白来源。
- 第三幕流程依据 [迫近的客星](https://wiki.biligame.com/ys/index.php?title=迫近的客星&oldid=673277)，重要转折分别依据 [离心](https://wiki.biligame.com/ys/index.php?title=离心&oldid=666992)、[回天](https://wiki.biligame.com/ys/index.php?title=回天&oldid=666994) 和 [送仙](https://wiki.biligame.com/ys/index.php?title=送仙&oldid=666990)。孤芳页面直读失败，只采用整幕索引支持的流程概述。

人物推断、港口流言、说书人的修辞与已发生事件分开表述。未公开的交易对价不自行补写。NPC 内容是这些任务中的片段摘要，不代表完整常驻 NPC 对话库。未收录第一章第四幕、所有任务分支、全量台词或语音。

内容沿用项目来源归属与许可说明，见 `SOURCES.md`。本批不新增游戏图片、音频或台词全文。

## 实现与验证

章节内容文件按同一结构生成程序包；短幕名作为范围识别别名，避免输入另一幕标题时仍检索当前幕。问答证据和模型返回都检查当前幕的受限词。检索与防剧透是规则实现，不能保证识别所有语义改写。

`npm test` 包含来源完整性、跨幕范围、后续追问、未知交易细节和同名页面检查。`npm run test:liyue-ui` 使用真实浏览器及本地模拟在线服务检查问答、出处、刷新和档案。桌面测试同时覆盖蒙德、璃月新正文，结果见 `VALIDATION.md`。
