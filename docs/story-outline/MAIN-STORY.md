# 主线讲解提纲

[返回总提纲](./README.md) · [逐项来源目录](./archon.md)

下面把已定位的章节排成讲解结构。每幕仍需继续展开子任务、场景和对白。章节顺序用于导航；并不表示玩家必须在这个顺序完成所有传说与世界任务。

## 贯穿全程的四条问题线

| 线索 | 要持续追踪的问题 |
| --- | --- |
| 旅行者与血亲 | 分离后双方分别经历了什么；相遇时各自掌握哪些信息；旅行目的怎样变化 |
| 国家、神明与民众 | 国家面对什么危机；神明、管理组织和普通人的立场如何不同；事件怎样改变日常生活 |
| 深渊、坎瑞亚与历史 | 当前调查、人物回忆、传说和历史记录分别提供什么证据；哪些仍然未知 |
| 世界规则与叙述差异 | 记忆、记录、梦境、预言和人物证言能证明什么；哪些说法只是特定人物当时的认知 |

不要把这四条线先汇总成全知时间线再喂给新玩家。每条结论都要继承其任务与证据的解锁条件。

## 第一章：璃月，以及第一次重要重逢

1. **浮世浮生千岩间**：进城与典仪 → 突发事件 → 旅行者的处境 → 寻求不同阵营的帮助。
2. **辞行久远之躯**：送别筹备 → 钟离同行与地方习俗 → 仙人与璃月港之间的关系。
3. **迫近的客星**：冲突集中 → 城市共同应对危机 → 事件收束后的身份、契约与治理问题。
4. **我们终将重逢**：单独放入“旅人线”标签；接续戴因斯雷布相关前置，整理深渊调查、血亲立场与旅行方向。

同时记录「拾枝者·戴因斯雷布」：它在世界任务目录中出现，但与魔神任务衔接紧密，不能因分类不同漏掉。[章节和前置来源](https://wiki.biligame.com/ys/魔神任务)

## 第三章：须弥，与卡利贝尔

1. **穿越烟帷与暗林**：初入雨林 → 接触当地学术与信仰体系 → 进入城市并建立关系。
2. **千朵玫瑰带来的黎明**：花神诞祭相关经历 → 异常的辨识 → 同伴如何逐步建立解释。
3. **迷梦与空幻与欺骗**：调查推进 → 信息真假与人物立场 → 向沙漠延展。
4. **赤土之王与三朝圣者**：沙漠调查 → 不同群体的历史认知 → 合作条件的形成。
5. **虚空鼓动，劫火高扬**：联合行动 → 营救与对抗 → 世界树相关揭示 → 城市生活的后续变化。
6. **卡利贝尔**：单独标为旅人线；先辨明观察视角与时间层，再整理家庭经历、诅咒和深渊线索。

世界树相关内容尤其需要区分“旅行者仍记得什么”“其他人物当时相信什么”“记录呈现什么”，不把几个状态混在同一段解释中。[第五幕来源](https://wiki.biligame.com/ys/虚空鼓动，劫火高扬)

## 第四章：枫丹，与睡前故事

1. **白露与黑潮的序诗**：进入枫丹 → 接触表演与审判 → 案件引出城市的矛盾。
2. **仿若无因飘落的轻雨**：继续调查 → 当事人的经历与证据 → 个人案件同更大危机的联系。
3. **向深水中的晨星**：进入梅洛彼得堡后的生活与调查 → 封闭场景中的信息搜集。
4. **谕示胎动的终焉之刻**：危机信号集中 → 各方准备与判断 → 预言问题逐渐逼近。
5. **罪人舞步旋**：多条调查线收束 → 芙宁娜与芙卡洛斯相关揭示 → 城市命运及人物后续。
6. **睡前故事**：转入旅人线；整理记忆、相遇与“命运的织机”的相关线索，避免用后续知识替代当时的认识。

不同人物知道真相的时间不同，讲解人物行为时要使用该场景下的知识范围。[第五幕来源](https://wiki.biligame.com/ys/罪人舞步旋)

## 间章

1. **风起鹤归**：群玉阁相关事件与申鹤的个人经历；人物与城市故事怎样交织。
2. **危途疑踪**：受困场景、队伍关系、层岩巨渊历史线索与脱困选择。
3. **倾落伽蓝**：散兵相关经历、世界树变化、记忆与记录之间的区别。[来源](https://wiki.biligame.com/ys/倾落伽蓝)
4. **悖理**：保留独立间章入口；人物、场景与主线衔接待逐条核对。

间章按各自的前置任务解锁，不统一放到“全部主线结束之后”。

## 每幕的下一级目录

统一展开为：前置与接取 → 子任务 → 地点/场景 → 强制对话 → 可选对话 → 玩家选项与汇合 → 演出及旁白 → 任务后 NPC → 关联物品文本 → 摘要与问答入口。

标题目录的目标是尽可能不漏章节；剧情事实的验收目标是每条结论都能回到具体证据。两者分别统计。
