# NPC 对话内容提纲

[返回总提纲](./README.md) · [NPC 名录](./npc.md) · [可搜索目录](./catalog.html)

目标是能回答“这个人是谁”“为什么这么说”“任务前后说法为什么不同”，而不只是查询一串名字。本轮先建立 2,139 条 NPC 名录记录，并整理下列对话结构与主题示例；没有完成全名录的逐句对白采集。

## 一个人物应包含哪些对话

| 对话层 | 应收录的内容 | 不能遗漏的条件 |
| --- | --- | --- |
| 初次接触 | 招呼、自我介绍、首次选项、初次赠礼 | 初见或再次见面；一次性标记 |
| 日常闲聊 | 全部可选话题、追问、返回上级、告别 | 当前地区、人物状态、解锁任务 |
| 待机与环境 | 自言自语、路过触发、两人互谈、广播 | 距离、时间、地点、是否可重复 |
| 店铺与服务 | 开店前后、菜单选项、购买以外的个人故事 | 营业时段、任务占用、好感或赠礼状态 |
| 任务开始前 | 任务尚未接取时的普通状态、可选提示 | 任务可接取/不可接取、前置条件 |
| 任务进行中 | 强制剧情、旁观者额外对话、重复询问 | 任务阶段、所在场景、刚刚做过的选择 |
| 分支与失败 | 互斥选项、拒绝、错误选择、失败反馈 | 选项路径、失败后是否重来、是否汇合 |
| 任务结束后 | 感谢、后日谈、身份揭示、消失或迁移 | 刚结束/次日/若干天后、是否一次性 |
| 委托故事 | 随机版本、完成次数变化、后续任务 | 地区委托、轮次、选择与成就前置 |
| 活动驻场 | 每阶段对话、各地点闲聊、最后一日收尾 | 活动 ID、版本、日期/阶段、主任务完成度 |
| 世界状态变化 | 国家大事件、战争前后、记忆与记录变化 | 已完成哪些任务；哪一套状态有效 |
| 特殊对象 | 非人类、投影、残影、意识、机关回应 | 世界状态、形态、环境切换与显现条件 |

任务之外的闲聊和任务页里的额外对话要交叉检查。BWIKI 的 NPC 编辑说明明确将活动剧情放到活动详情页，因此仅扫描 NPC 页面会漏掉部分活动对话。[编辑说明来源](https://wiki.biligame.com/ys/用户:10977852/NPC)

| 地区 | 人群与地点线索 | 对话内容检查方向 |
| --- | --- | --- |
| 蒙德 | 城门、广场、教堂、酒馆、骑士团、清泉镇、酒庄、雪山营地 | 信仰、家人、工作、龙灾与远征消息；日常和委托的交叉 |
| 璃月 | 港口、商铺、茶馆、轻策庄、望舒客栈、矿区、沉玉谷 | 商业与契约、地方传说、迁居与家庭、仙人与普通人的不同讲述 |
| 稻妻 | 离岛、三奉行相关地点、神社、各岛村落、海祇岛、渊下宫 | 政令和战争对生活的影响；昼夜、跨天、常夜/白夜及残影条件 |
| 须弥 | 须弥城、教令院、港口、村落、沙漠营地、兰那罗聚居地 | 学术、知识来源、地方信仰、身份差异、梦境与现实；地区名录仍缺 |
| 枫丹 | 城区、报社、歌剧院、梅洛彼得堡、科学院、美露莘村落 | 审判和证词、工作、家庭、科研、个体与社会认知 |
| 纳塔 | 各部族聚落、竞技场、营地、遗迹、龙伙伴相关地点 | 传统、古名、训练与伙伴关系、战事前后、非人类视角 |
| 挪德卡莱 | 那夏镇、工坊、各聚所、银月之庭等目录入口 | 地方生活、商店人物、聚所阶段、主线前后变化；地区名录仍缺 |
| 至冬及新区域 | 以任务和版本专题中实际定位的场景逐项补充 | 地区页读取失败，暂不编造全人物表或未核实的谈话主题 |

人物国籍、来源页面分组、目前所在地区是三个不同字段。某个 NPC 出现在“纳塔”索引里，不足以证明其当前位于纳塔。

## 已核对来源的主题示例

下列是自行归纳的整理示例，不是逐字对白，也不表示该人物所有分支已核对。

### 提米、葛瑞丝与杜拉夫

- **日常问题**：提米对鸟类的态度，从哪些日常对话和任务能找到背景？
- **委托线**：鸟类相关行为 → 道歉相关任务 → 给父亲写信、寻找送信办法。
- **人物关系**：提米如何称呼葛瑞丝；葛瑞丝实际承担什么照护角色；杜拉夫为何被请求帮忙。
- **叙述边界**：提米对父亲的想法是孩子当时的认知，不能未经其他证据就改写成客观结论。
- **要补的节点**：接取、准备物品、交付前重复交谈、可选询问、结束后反馈、失败与后续条件。

[一个男孩的去信](https://wiki.biligame.com/ys/一个男孩的去信) · [提米，对不起！](https://wiki.biligame.com/ys/提米，对不起！)

### 葛罗丽与古德温

- **共同主题**：分离、思念与双方掌握的信息。
- **独立入口**：葛罗丽的普通谈话、相关委托、古德温的场景，以及活动中的补充谈话。
- **讲解问题**：谁向谁传达了什么；人物相信的情况与旅行者亲眼看到的情况是否相同。
- **版本分开**：风花节中的思念不能覆盖掉平时的对话，也不自动成为所有时点都成立的状态。

[愿风带走思念](https://wiki.biligame.com/ys/愿风带走思念) · [风花的呼吸活动页](https://wiki.biligame.com/ys/「风花的呼吸」)

### 柳德米拉：主线进度改变闲谈

- **整理方式**：以 NPC 页面上的“完成某幕”条件分段，而不是生成一份无条件台词列表。
- **讲解问题**：不同国家的大事件发生后，她怎样理解和转述消息；这些评论表达什么立场。
- **防剧透重点**：用户身在蒙德，并不意味着蒙德所有 NPC 的后期闲谈都可以展示。
- **要补的节点**：各阶段触发条件、是否替换旧台词、与另一位谈话者的来回顺序。

[柳德米拉来源](https://wiki.biligame.com/ys/柳德米拉)

### 茶博士刘苏：人物谈话与说书文本

- **话题层**：职业、说书、关于行秋的相关谈话。
- **材料分层**：NPC 本人正在做什么，与他讲的故事中发生什么，分别记录。
- **讲解问题**：这是亲历、听闻还是文学化叙述；哪些细节可以由其他任务独立印证。
- **身份注意**：来源标题为“茶博士刘苏”，不要仅凭用户输入“刘苏”新建另一名人物。

[茶博士刘苏来源](https://wiki.biligame.com/ys/茶博士刘苏)

### 寝子、浅濑神社与阿响

- **日常线**：神社、照顾小猫、维护与修复。
- **连续事件**：逐日委托式的请求、参与人物、结束后的变化。
- **历史线**：寝子的等待与人类所查到的历史记录如何对照。
- **叙述边界**：寝子的时间认知不能直接换算成精确年表；历史记载不完整时保留不确定性。
- **任务外内容**：相关任务中大岛纯平、悦子、大祐、稻城萤美的额外谈话也要收录。

[寝子是只猫·孩子们](https://wiki.biligame.com/ys/寝子是只猫·孩子们) · [迟来的好事](https://wiki.biligame.com/ys/寝子是只猫·迟来的好事) · [鸣神寻踪](https://wiki.biligame.com/ys/鸣神寻踪)

### 阿芬迪：功能解锁对话也包含世界设定

- **情境**：协助人员招募。
- **内容**：介绍自身的联络工作，解释教令院与三十人团的协作、城市防务与居民委托。
- **讲解问题**：某个组织为什么需要旅行者帮助；哪些事务属于日常民生。
- **整理重点**：保留“已了解招募”和“询问是什么”的选项分支及汇合，不把两种回答当成连续对话。

[三十人团的招募](https://wiki.biligame.com/ys/「三十人团」的招募)

### 卡嘉：常驻商店与任务后的一次性对话

- **普通谈话**：经营餐馆、店员的处境、以前从事的工作。
- **任务后谈话**：与梅蒂相关任务结束后，在餐馆发生的额外交流。
- **讲解问题**：为什么某个选项只出现一次；她对店员和朋友的态度体现在哪里。
- **保存条件**：任务完成、首次交流、特定任务物品是否仍在背包中，以及交流后的物品变化。

[卡嘉](https://wiki.biligame.com/ys/卡嘉) · [镜子、迷宫与国王的任务后对话](https://wiki.biligame.com/ys/镜子、迷宫与国王)

## 每个 NPC 的提纲模板

```text
人物条目
  身份：来源人物 ID、页面名、别名、身份消歧状态
  出现：实际地点、来源分组、任务阶段、时段、版本
  关系：与谁有关，依据哪段对话；哪些只是自称或他人说法
  日常：首次 / 重复 / 招呼 / 所有话题 / 告别 / 待机
  任务：任务 ID → 阶段 → 场景 → 对话入口
  活动：活动 ID + 版本 → 阶段 → 驻场地点 → 对话
  分支：选择条件 → 选项 → 后继节点 → 汇合或结束
  变化：任务前后、世界状态、迁移、离场、一次性内容
  问答：身份、动机、关系、已知与未知、信息变化
  证据：来源 URL、原文位置、获取日期、校验状态
```

对话节点另存 `speakerId`、`sceneId`、`rawText`、`optionGroupId`、`nextIds`、`conditions`、`worldState`、`sourceLocator`。这只是下一步入库约定，本轮不生成空的“已完成对白”，也不把整理者写的摘要放入 `rawText`。

## 如何判断一名 NPC 已整理完

1. 已确认人物身份，同名人物有明确区分。
2. 所有已知出现位置、任务、活动及版本都有检查记录。
3. 每个对话入口的选项、后继、汇合和结束节点均有出处。
4. 日常、任务中、任务后及活动状态均经过检查，缺项明确写“缺少来源”。
5. 逐字原文、内容摘要、人物观点和整理者推断分开保存。
6. 不能根据“存在 NPC 页面”或图鉴图标认定对白完整。

未满足这些条件时，状态保持“名录已收录 / 对话待核对”。
