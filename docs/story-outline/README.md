## 剧情怎样展开

每个任务或短篇统一整理为以下提纲，后续再挂接逐句原文：

1. **定位**：任务类型、所属章节、地区、人物、版本、是否限时。
2. **起因**：谁提出了什么问题；旅行者为何介入；前置事件是什么。
3. **发展**：按实际发生的场景拆分，不按 Wiki 页面顺序或文本 ID 排时间。
4. **关键揭示**：新获得的信息、人物关系变化；是谁在什么条件下说出的。
5. **选择**：可选回答、互斥路线、汇合点、失败和重复节点。
6. **收束**：直接结果、未解疑点、任务后的 NPC 状态及新增对话。
7. **关联**：与主线、其他支线、书籍物品的联系；事实联系和分析推断分别记。
8. **问答入口**：发生了什么、为什么、人物知道多少、还有哪些证据。

对话也分两种检索入口：按任务查“当时说了什么”，按人物查“在不同阶段说过什么”。两种入口引用同一个对话节点，避免把同一台词复制成多份互相矛盾的材料。

## NPC 对话的覆盖原则

NPC 不只是任务发放者。路人、商贩、学者、儿童、守卫、非人类生命、幻影、活动临时角色和离场角色都进入检查范围。只被提及的人物建立人物条目，但不凭空补出其对话。

同名并不等于同一人；多个地点出现也不必然是不同人。先保存来源位置与人物标识，取得足够依据后再合并。同一句话在不同世界状态下可能含义不同，必须保留触发条件。

已完成的是目录与整理结构，NPC 对话章节另有少量基于来源的主题示例；没有声称获得全游戏逐字脚本。现有桌宠的 14 条精选资料保持独立。

三份 NPC 地区页和活动任务总表本次无法读取；分类页有旧缓存，多个动态页面不能凭修订号判断内容是否同步。新章节暂记录索引与更新专题中确认出现的标题，情节细节及官方实装状态仍需独立核验。详见[覆盖报告](./COVERAGE.md)。
