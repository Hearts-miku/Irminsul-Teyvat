剧情目录可按整幕或子任务名搜索，例如“有隔阂的魂灵”“南十字武斗会”。主题独立，不会因为编号较大而放开其他章节。前置任务不提前说明戴因后续身份；序幕不提前使用稻妻后续决战的结论。

可以提问：戴因的三个问题有正确答案吗？重逢后为什么没有一起回家？戎世为什么不羡慕神之眼？万叶为什么没有立刻阻止偷窃？北斗是否第一次见旅行者？

本批直接核对 API 缓存中的任务场景，固定来源包括 [拾枝者·戴因斯雷布](https://wiki.biligame.com/ys/index.php?title=拾枝者·戴因斯雷布&oldid=667067)、[我们终将重逢](https://wiki.biligame.com/ys/index.php?title=我们终将重逢&oldid=673278)、[有隔阂的魂灵](https://wiki.biligame.com/ys/index.php?title=有隔阂的魂灵&oldid=674113)、[振袖秋风问红叶](https://wiki.biligame.com/ys/index.php?title=振袖秋风问红叶&oldid=673279) 及各子任务。完整十页清单和场景哈希位于 `data/source-receipts/journey-bridge.json`。

目前是重点剧情及部分 NPC 片段摘要，不是逐句对白库。血亲是否为最高统治者、命运的织机后续发展、神之眼完整运行原理等不在本批证据范围内。北斗见面对白保留“风起鹤归”完成前后的条件差异；万叶的实验失败不能外推为永远不可能成功。

自动化的用法、核对边界与采集测试见 [CONTENT-AUTOMATION.md](CONTENT-AUTOMATION.md)，运行验证见 [VALIDATION.md](VALIDATION.md)。
